## About This Repository

This repository contains data analysis projects completed using Microsoft Excel. It demonstrates my ability to clean, explore, and visualise data using pivot tables, formulas, and dashboards — skills directly applicable to financial analysis and business reporting.

---

## Projects

### 1. 📦 Sales Performance Dashboard
- Analysed monthly sales data across product categories
- Built pivot tables to summarise revenue by region and period
- Created dynamic dashboard with slicers for interactive filtering
- **Key Insight:** Identified top 3 performing regions contributing 68% of total revenue

### 2. 🌾 IITA Crop Disease Surveillance Summary
- Cleaned and organised field data collected across experimental plots
- Used pivot tables to compare disease incidence rates by season and location
- Applied conditional formatting to flag high-risk plot zones
- **Key Insight:** Disease incidence was 40% higher in plots with below-average rainfall

### 3. 🏦 Bank Customer Transactions Analysis
- Analysed sample customer transaction data (deposits, withdrawals, transfers)
- Built charts showing transaction frequency by day of week and customer segment
- Summarised average balance trends over 12 months
- **Key Insight:** Transaction volumes peak on Mondays and end-of-month periods

## How to Use
1. Download any `.xlsx` file from this repository
2. Open in Microsoft Excel 2016 or later
3. Enable macros if prompted
4. Use slicers/filters to explore the data interactively
